# 发布前自检

在给出最终结论前逐项确认。

## 数据

- [ ] 公司、代码、交易所、货币和数据截止日正确。
- [ ] 已识别行业、生命周期和对应指标路由。
- [ ] 关键财务数字来自原始披露或已明确标注的可靠数据源。
- [ ] 已区分完整年度、TTM、预测值和正常化值。
- [ ] 使用稀释后股本，并处理回购、增发、股权激励和可转债。
- [ ] 跨市场比较已处理币种、财年和会计口径。
- [ ] 缺失和冲突数据已披露，没有编造。

## 公司质量

- [ ] 商业模式和增长来源能够用一句话解释。
- [ ] 增长同时检查收入、EPS、FCF 和每股 FCF。
- [ ] 已判断增量资本回报、增长跑道和并购依赖。
- [ ] 护城河有量化证据和证伪条件。
- [ ] 海外收入按盈利、本地化和分散度评价，不只看占比。
- [ ] 已检查治理、关联交易和资本配置历史。

## 分红与股东回报

- [ ] 同时计算利润分红率和 3–5 年累计 FCF 分红率。
- [ ] 高资本开支公司同时展示报告 FCF 与明确标为估算的所有者收益近似值。
- [ ] 股息增长与每股 FCF 增长相匹配。
- [ ] 特别股息与基础股息分开。
- [ ] 回购已扣除增发和股权激励稀释。
- [ ] 已做衰退、利润率、资本开支和融资成本压力测试。
- [ ] 已排查借债分红、资产出售分红和周期顶部高股息。

## 评分

- [ ] 九项正向星级均有至少一条可核验证据，治理一致性单独评分。
- [ ] 资本配置评价决策，股东回报评价实际结果，未重复计分。
- [ ] 周期性明确标为风险星级，未与正向星级混淆。
- [ ] 结构周期风险影响质量分，当前周期位置只影响正常化盈利和估值。
- [ ] 综合评级由分数推导，并应用硬性评级上限。
- [ ] 公司质量评级和当前估值判断分开。
- [ ] 数据不足时降低置信度和评级上限。

## 估值

- [ ] 使用至少两种适用方法交叉验证。
- [ ] 未使用无来源的固定行业 PE。
- [ ] FCF 估值包含净债务、非经营资产和稀释后股本桥接。
- [ ] 已给悲观、中性、乐观三情景及 3–5 年年化总回报。
- [ ] 当前价格隐含的增长、利润率或终值假设已写明。
- [ ] 已以交易货币/股明确给出“较强安全边际、合理偏低、合理、偏贵”四档连续且不重叠的价格区间。
- [ ] 已标明当前价格、价格截止日、所在档位，以及中性情景下 8%、10%、12% 目标回报对应价格。
- [ ] 若无法估算价格区间，已明确列出缺失数据与补全条件，而非省略或伪造精确值。
- [ ] 未把已计入 EPS 的回购再次重复计入总回报。

## 表达与风险

- [ ] 全文中文，先结论后依据。
- [ ] 事实、预测、假设和判断明确分开。
- [ ] 无“必涨、稳赚、抄底”等保证性表述。
- [ ] 输出否决条件、监控指标和数据缺口。
- [ ] 未给固定仓位比例或个性化交易指令。
- [ ] 已注明研究用途，不构成投资建议。
