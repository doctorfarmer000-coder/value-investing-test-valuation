## 使用原则

先识别行业经济模型，再选择指标和正常化方法。跨行业比较时，不要机械比较 PE、ROE、海外收入占比或分红率。

## 生命周期与指标路由

评分前选择最接近的企业类型；类型决定重点指标和可放宽指标，不直接决定分数。

| 类型 | 重点指标 | 口径调整 |
|---|---|---|
| 成熟现金流型 | 报告 FCF、股息增长、净回购、资产负债表 | 严格检查现金覆盖 |
| 高 ROIC 扩张型 | 增量 ROIC、增长跑道、OCF、单位经济 | 降低当期股息与单年 FCF 权重 |
| 资本密集扩张型 | 增量 ROIC、产能利用率、OCF、项目回报 | 单年 FCF 结合成长资本开支解释 |
| 周期型 | 中周期盈利、供需库存、单位成本、低谷偿债 | 禁止外推当前 PE 与利润 |
| 监管型公用事业 | 监管回报率、维护资本开支、债务期限 | 使用行业资本结构口径 |
| 复杂金融机构 | 资本充足率、资产质量、准备金、偿付能力 | 转金融专门模型 |

## 消费与品牌

重点检查：

- 品牌溢价、复购、渠道库存和促销依赖。
- 同店、销量、价格和产品结构贡献。
- 销售费用率增长是否换来可持续份额。
- 存货减值、经销商压货和应收风险。
- 海外品牌本地化，而不只是出口额。

护城河证伪：持续降价、复购下降、渠道流失、爆品老化、份额靠补贴维持。

## 制造与出口

重点检查：

- 全球份额、成本曲线、技术/认证、客户切换成本。
- 海外收入的地区和客户集中度、当地制造与服务能力。
- 关税、汇率、制裁、贸易壁垒和供应链迁移风险。
- 资本开支周期、产能利用率、订单质量和营运资本。
- 大客户依赖、应收账款、质保和召回风险。

海外收入高但低毛利、回款差、单一市场集中时，不得给高星。

## 通信与公用事业

重点检查：

- 监管定价、用户/流量增长、ARPU 和竞争格局。
- 维护性资本开支、频谱费用、折旧与真实 FCF。
- 净负债、利息覆盖和长期项目回报。
- 分红政策与监管资本要求。

这些行业通常增长较慢但现金流可见度较高。高分红率可接受程度应结合资本开支和杠杆，而不是套用消费股标准。

## 周期与航运

重点检查：

- 使用 5–10 年中周期价格、运价、利用率和利润率正常化盈利。
- 识别供给周期、订单簿、产能投放、库存和成本曲线。
- 把特别股息和周期顶部分红与基础股息分开。
- 使用净现金、资产价值、单位成本和压力情景，不得只看顶部低 PE。
- 评级中提高周期风险星级，并限制依赖顶部盈利的综合评级。

周期公司的优秀表现是低谷仍能生存并逆周期配置资本，不是高峰期利润最高。

## 软件与平台

重点检查：

- 经常性收入、留存、客户获取成本、毛利率和现金转化。
- 股份支付、稀释后股本和净回购。
- 资本化开发支出和调整后利润口径。
- 分红不应挤压高回报再投资；低股息不自动降低公司质量，但会影响股息质量维度。

## 不适用范围

银行、保险、券商和复杂金融机构需要资本充足率、资产质量、准备金、偿付能力和内含价值等专门框架。遇到这些行业时，说明本 Skill 不适合做完整结论，并转用金融行业专门方法。
