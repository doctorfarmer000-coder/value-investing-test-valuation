## 估值原则

使用至少两种适用方法交叉验证。估值必须和增长、资本回报、分红能力、资产负债表及周期位置一致。

估值不计入公司质量分。分别输出：

- 公司质量评级。
- 当前估值判断。
- 未来 3–5 年预期总回报范围。
- 结论对哪些关键假设最敏感。

## 正常化盈利

先判断当前利润处于正常、中周期、低谷还是高峰。

- 剔除明确的一次性资产处置、重大减值和非持续补贴。
- 不得随意剔除长期反复发生的股份支付、重组或“调整项”。
- 周期公司使用中周期价格、利润率、利用率和维护性资本开支。
- 使用稀释后 EPS；检查回购、增发和可转债影响。
- Forward 数据注明预测来源、预测日期和分歧程度。

## 相对估值

适用时比较：

- 正常化 PE 和 Forward PE。
- EV/EBIT、EV/EBITDA 与 EV/FCF。
- FCF 收益率、股息收益率和股东收益率。
- 历史估值区间和可比公司估值。

可比公司必须在商业模式、增长、利润率、ROIC、杠杆和会计口径上具有可比性。历史低分位不是低估的充分条件。

合理倍数必须写出依据，不使用无来源的固定行业 PE 表。

## 自由现金流估值

不得使用“自由现金流 ÷ 要求收益率 = 每股合理价”的简化公式。

使用 FCFF 时：

```text
企业价值 = 预测期 FCFF 现值 + 终值现值
股权价值 = 企业价值 - 净债务 - 少数股东权益 + 非经营资产
每股价值 = 股权价值 / 稀释后股本
```

使用 FCFE 时：

```text
股权价值 = 预测期 FCFE 现值 + 终值现值
每股价值 = 股权价值 / 稀释后股本
```

明确折现率、终值增长、利润率、再投资率、资本开支、营运资本和净债务假设。至少提供折现率与终值增长敏感性。

## 股息贴现

仅对分红政策稳定、盈利和 FCF 可预测、分红与可分配现金关系清晰的公司使用。

稳定增长模型：

```text
股权价值/股 = 下一期每股股息 / (股权成本 - 永续股息增长率)
```

必须满足股权成本高于永续增长率，并对股权成本和增长率做敏感性分析。高速增长或分红率正在改变时，使用多阶段模型。

## 反向估值

从当前股价反推出市场隐含假设：

- 收入或 EPS 需要增长多少？
- 利润率需要达到什么水平？
- 需要维持多长时间？
- 终值倍数或长期增长率是多少？
- 当前股价是否要求公司突破历史最佳水平？

把隐含假设与公司的历史、行业容量、竞争格局和资本需求比较。

## 三情景总回报

默认预测 3–5 年，分别建立悲观、中性和乐观情景。每个情景至少包含：

- 收入、EPS/FCF 增长。
- 期末利润率或正常化盈利。
- 期末合理估值倍数。
- 预计累计现金股息。
- 净回购或稀释影响。
- 期末价格和年化总回报。

```text
期末价格 = 期末稀释后 EPS × 期末合理 PE
年化总回报 = ((期末价格 + 持有期累计每股股息) / 当前股价)^(1/持有年数) - 1
```

若回购已经体现在稀释后 EPS，不要再次把回购收益重复加到总回报。

| 情景 | 核心假设 | EPS/FCF 增长 | 期末估值 | 累计股息 | 年化总回报 |
|---|---|---:|---:|---:|---:|
| 悲观 | 需求/利润率承压 |  |  |  |  |
| 中性 | 基本面按正常路径发展 |  |  |  |  |
| 乐观 | 份额和效率改善 |  |  |  |  |

## 观察区间

根据用户要求回报率或机会成本反推价格。用户未提供要求回报率时，同时展示 8%、10%、12% 三档敏感性，不把其中任何一档描述为保证收益。

每次个股估值必须输出以下四档、以交易货币/股表示的连续且不重叠的价格区间。不得只给单点目标价、PE/PB/FCF 倍数，或只写“便宜、合理、偏贵”。区间边界应结合公司类型、正常化盈利和三情景估值确定；若用户另行指定要求回报率，应据此调整分档标准。

| 价格档位 | 默认含义 |
|---|---|
| 较强安全边际 | 中性情景通常满足不低于 12% 的年化总回报，且压力情景损失可控 |
| 合理偏低 | 中性情景通常满足约 10%–12% 的年化总回报 |
| 合理 | 中性情景通常满足约 8%–10% 的年化总回报 |
| 偏贵 | 中性情景低于约 8% 的年化总回报，或价格已明显透支乐观情景 |

强制输出表：

| 标的 | 较强安全边际 | 合理偏低 | 合理 | 偏贵 | 当前价格/档位 |
|---|---:|---:|---:|---:|---|
| 公司 | 货币/股区间 | 货币/股区间 | 货币/股区间 | 货币/股区间 | 价格、日期、档位 |

同时列出中性情景下的目标回报价格：

| 目标年化总回报 | 12% | 10% | 8% |
|---|---:|---:|---:|
| 对应最高买入价 |  |  |  |

```text
满足目标回报的当前价格 = (期末价格 + 累计股息) / (1 + 目标年化回报率)^持有年数
```

输出：

- 压力情景仍可接受的研究区间。
- 中性情景满足目标回报的观察区间。
- 当前价格、价格截止日、所在档位、隐含回报和安全边际。
- 四档区间的具体上下界、8%/10%/12% 对应价格及其核心假设；边界按可执行的价格精度合理取整。
- 需要重新评估而不是机械加仓的低价区间。

普通公司优先用正常化 EPS/FCF 与合理期末估值交叉验证；银行等金融机构使用 PB、ROE、股息和资本充足性框架；强周期公司使用全周期正常化盈利。若可靠数据不足，必须输出“暂无法估算价格区间”，列出缺失数据、补全条件和不能可靠估算的原因。

禁止只给一个目标价。禁止把估值区间直接转换为固定仓位建议。
