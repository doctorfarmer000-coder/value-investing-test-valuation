# 数据与来源清单

## 目录

- 时点与来源
- 基础信息
- 增长与盈利
- 现金流与分红
- 资本结构与股本
- 竞争力与海外业务
- 数据质量规则

## 时点与来源

默认收集 5–10 个完整年度、最近 8 个季度、最新股价和最新正式披露。数据不足时说明缺口。

来源优先级：

1. 交易所公告、监管文件和经审计年报。
2. 公司季报、业绩公告、投资者关系材料和电话会资料。
3. 正规市场数据与一致预期服务。
4. 高质量行业资料和可信新闻，仅用于补充竞争与事件背景。

对股价、估值和一致预期注明抓取日期；对财务数据注明报告期。预测数据不得伪装成已报告事实。

## 基础信息

| 字段 | 要求 |
|---|---|
| 公司、代码、交易所 | 核对同名公司和上市地点 |
| 行业和商业模式 | 说明收入来源、客户和价值链位置 |
| 生命周期与指标路由 | 标记成熟现金流、高 ROIC 扩张、资本密集扩张、周期、监管或金融专用类型 |
| 报告货币和交易货币 | 跨市场时说明汇率日期 |
| 稀释后总股本 | 用于每股指标，说明期权/可转债影响 |
| 当前股价和市值 | 注明日期，避免与财报期末混用 |
| 企业价值 | 说明现金、债务、少数股东和非经营资产调整 |

## 增长与盈利

至少收集收入、归母净利润、稀释后 EPS、毛利率、营业利润率、ROIC/ROE、经营现金流、资本开支和自由现金流。

计算或记录：

- 收入、EPS、FCF、每股 FCF 的 3/5/10 年 CAGR。
- 各指标年度序列和最大下滑，不只列起止值。
- 有机增长、并购、价格、销量、结构和汇率贡献。
- 增量 ROIC 或新增资本的回报证据。
- 存货、应收、合同资产和商誉相对收入的变化。

## 现金流与分红

| 字段 | 用途 |
|---|---|
| 经营现金流 | 验证利润现金含量 |
| 总资本开支 | 计算 FCF；尽量区分维护和成长资本开支 |
| 所有者收益近似 | 仅在维护性资本开支可以合理估算时使用，并明确标为分析值 |
| 普通股现金股息 | 计算利润和 FCF 分红率 |
| 每股股息 | 计算 3/5/10 年股息 CAGR |
| 回购金额 | 与发行、股权激励和实际股本变化对照 |
| 特别股息 | 与基础股息分开 |
| 分红削减记录 | 检查衰退和行业低谷表现 |
| 分红政策 | 目标分红率、最低分红或管理层承诺 |

## 资本结构与股本

- 现金、短期投资、有息债务、租赁负债和净负债。
- 净负债/EBITDA、利息覆盖、债务到期结构和融资成本。
- 稀释后股本 3/5/10 年变化。
- 股份支付、可转债、并购增发和员工持股计划。
- 并购支出、资产处置、商誉、减值和少数股东权益。
- 养老金、担保、诉讼、环保和其他或有负债。

## 竞争力与海外业务

为图片式参数表收集：

- 国内和全球市场份额、行业排名及变化。
- 海外收入占比、海外利润率和增长率。
- 海外地区、客户和渠道集中度。
- 当地制造、研发、品牌、销售和售后能力。
- 核心技术、专利、认证、标准、品牌和成本优势。
- 客户留存、复购、转换成本、渠道控制和定价权证据。
- 汇率、关税、贸易限制、地缘和本地监管风险。
- 行业周期变量：价格、运价、库存、订单、产能利用率或资本开支。

## 数据质量规则

- 统一财年、币种和会计口径后再比较。
- 区分 TTM、完整年度、预测年度和中周期正常化数据。
- 跨市场可比公司先调整业务结构、税率、杠杆和会计差异。
- 发现财报重述时使用最新重述值并注明。
- 数字无法由来源复核时标记 `未核实`，不得给满星。
- 数据冲突时记录来源差异，不得选择最有利于既有结论的数字。
- 输出数据置信度分数及高/中高/中/低标签，并列出覆盖年限、来源质量和关键缺口。
