## 评分原则

先依据数据和事实给每个维度评分，再计算综合评级。不要用综合评级反推单项星级。

- 九项正向质量分满分 100 分。
- 周期性单独作为风险星级，并从质量分中扣分。
- 估值不进入公司质量分，另行判断低估、合理或偏贵。
- 海外收入不是必备条件；对纯内需垄断、公共服务等不依赖全球化的行业，标记 `不适用`，按 3 星中性计分并解释。

## 参数总表

| 参数 | 权重 | 主要证据 |
|---|---:|---|
| 增长质量 | 20 | 收入、EPS、FCF 的 3/5/10 年增长，增量 ROIC，增长来源 |
| 股息质量 | 15 | 分红连续性、股息 CAGR、FCF 分红率、覆盖倍数、削减记录 |
| 股东回报 | 5 | 实际股息、净回购、股本稀释和每股回报结果 |
| 资本配置 | 15 | 再投资回报、并购纪律、降债、回购价格纪律、闲置现金使用 |
| 护城河 | 15 | 定价权、成本优势、转换成本、网络效应、渠道、牌照与证伪信号 |
| 全球竞争力 | 10 | 全球份额、品牌/技术/标准、成本曲线、本地化和跨区域盈利能力 |
| 财务稳健性 | 10 | 净负债、利息覆盖、流动性、期限结构、或有负债 |
| 海外收入与市场多元化 | 5 | 海外收入质量、地区/客户分散、本地化、汇率和贸易风险 |
| 治理一致性 | 5 | 控股股东、关联交易、审计、长期激励、信息披露和中小股东保护 |
| **正向质量分** | **100** | 各项加总 |

把 1–5 星映射为该维度权重的 20%、40%、60%、80%、100%。允许半星；半星按 10% 权重递增。

## 星级定义

### 增长质量

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 收入、每股收益或 FCF 长期下降；增长依赖周期价格或并购 |
| ★★☆☆☆ | 增长弱且波动大，现金流跟不上利润 |
| ★★★☆☆ | 中等增长，来源基本可解释，但持续性仍需验证 |
| ★★★★☆ | 多周期保持有机增长，EPS 与 FCF 同步，增量回报良好 |
| ★★★★★ | 5–10 年稳定复利，增长跑道长，增量 ROIC 高且股本稀释低 |

### 股息质量

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 分红不稳定、曾频繁削减，或主要依靠举债/处置资产 |
| ★★☆☆☆ | 有分红但覆盖薄弱，FCF 分红率长期偏高 |
| ★★★☆☆ | 分红基本可持续，增速有限，偶有周期性波动 |
| ★★★★☆ | FCF 覆盖良好，分红稳定增长，资产负债表支持 |
| ★★★★★ | 长期稳定增长、覆盖充足、政策透明，衰退期仍有承受能力 |

### 股东回报

同时评价现金分红、净回购和股本稀释。把员工激励和增发从回购中扣除。

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 长期稀释或损害中小股东，缺少可验证的回报纪律 |
| ★★☆☆☆ | 偶有分红/回购，但连续性差或回购价格不合理 |
| ★★★☆☆ | 能稳定返还部分现金，净稀释可控 |
| ★★★★☆ | 分红与净回购持续，兼顾再投资和财务安全 |
| ★★★★★ | 长期每股价值导向明确，分红增长、逆周期回购和稀释控制优秀 |

### 资本配置

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 高价并购、无效扩张、借债分红或长期低回报投资 |
| ★★☆☆☆ | 资本使用效率偏低，战略反复，回购缺乏价格纪律 |
| ★★★☆☆ | 再投资、分红、降债基本合理，但历史记录一般 |
| ★★★★☆ | 增量投资回报良好，并购和股东回报较有纪律 |
| ★★★★★ | 长期以每股内在价值为核心，能动态选择再投资、回购、分红和降债 |

资本配置评价决策质量；股东回报评价实际分红、净回购和稀释结果。同一事实不得在两项重复加分。

### 治理一致性

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 存在重大审计、资金占用、利益输送或信息披露问题 |
| ★★☆☆☆ | 关联交易复杂，激励偏规模，治理改善缺乏验证 |
| ★★★☆☆ | 基本合规，控股股东与管理层行为总体可接受 |
| ★★★★☆ | 战略和披露稳定，激励重视每股价值与长期回报 |
| ★★★★★ | 治理透明，利益高度一致，能坦诚纠错并长期保护中小股东 |

### 护城河

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 同质化严重、价格接受者、客户可轻易切换 |
| ★★☆☆☆ | 有规模或渠道优势，但定价权弱、易被复制 |
| ★★★☆☆ | 存在可验证优势，但范围或耐久性有限 |
| ★★★★☆ | 品牌、成本、渠道、技术或转换成本形成持续优势 |
| ★★★★★ | 多重护城河叠加，份额和单位经济长期稳定，并有清晰证伪指标 |

### 全球竞争力

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 主要依赖单一地区，国际竞争中缺乏成本、品牌或技术优势 |
| ★★☆☆☆ | 有出口但以价格竞争为主，海外盈利和本地化较弱 |
| ★★★☆☆ | 在部分区域/细分品类有竞争力，海外盈利可验证 |
| ★★★★☆ | 全球份额、品牌、技术或成本优势明显，区域分布较均衡 |
| ★★★★★ | 全球领导者，掌握品牌/标准/供应链/成本曲线，跨周期保持回报 |

### 财务稳健性

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 再融资或流动性风险高，利息覆盖弱，债务快速上升 |
| ★★☆☆☆ | 杠杆偏高，对利润、利率或资产出售敏感 |
| ★★★☆☆ | 杠杆可控，现金流一般，能够覆盖常规资本需求 |
| ★★★★☆ | 净负债低、利息覆盖充足、期限结构合理 |
| ★★★★★ | 净现金或极强现金创造力，压力情景下仍能投资和分红 |

### 海外收入与市场多元化

不要只按海外收入占比打分，必须同时检查盈利质量、地区/客户集中度、本地化和政治贸易风险。

| 星级 | 定义 |
|---|---|
| ★☆☆☆☆ | 海外业务很少，或高度集中且长期亏损/回款差 |
| ★★☆☆☆ | 初步出口，依赖单一市场、单一客户或低毛利代工 |
| ★★★☆☆ | 海外收入具有一定规模，盈利和风险基本可控 |
| ★★★★☆ | 多地区盈利、本地化经营、客户分散，海外业务形成第二增长曲线 |
| ★★★★★ | 全球收入高度多元且高质量，区域冲击不改变长期现金流能力 |

## 周期性风险

周期星级含义与其他维度相反：**星越多，周期风险越高。**

| 风险星级 | 特征 | 扣分 |
|---|---|---:|
| ★☆☆☆☆ | 必选消费、订阅、公共服务等需求稳定，利润波动小 | 0 |
| ★★☆☆☆ | 温和耐用品或弱周期，库存和利润波动可控 | -2 |
| ★★★☆☆ | 明显经济敏感，利润率与库存存在周期 | -5 |
| ★★★★☆ | 强周期，价格/产能/资本开支显著驱动盈利 | -9 |
| ★★★★★ | 极强周期，利润可在高峰和低谷间剧烈变化或转亏 | -14 |

```text
调整后质量分 = 九项正向质量分之和 - 结构周期风险扣分
```

周期属性是长期质量风险；当前处于周期顶部、中部或底部不得改变本项扣分，只能调整正常化盈利和估值假设。

## 综合评级

| 调整后质量分 | 初始评级 |
|---:|---|
| 90–100 | S |
| 85–89.9 | S- |
| 80–84.9 | A+ |
| 75–79.9 | A |
| 70–74.9 | A- |
| 65–69.9 | B+ |
| 60–64.9 | B |
| 50–59.9 | C |
| < 50 | D |

S/S- 还必须同时满足：股息质量、资本配置、护城河、财务稳健性和治理一致性均不低于 4 星；最近 5 年不存在未解释的重大分红削减或持续净稀释。

## 硬性上限

出现以下情况时，即使机械分数更高，也要限制评级：

- 分红长期超过 FCF 且依赖举债：最高 B。
- 重大治理、审计或资金占用问题：最高 C，并标记否决。
- 持续增发导致每股价值下降：最高 B+。
- 高度依赖周期顶部利润且未正常化：最高 B+。
- 数据覆盖不足三个完整年度：不得给 S/S-/A+，并降低置信度。
