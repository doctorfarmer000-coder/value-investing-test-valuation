# 分析流程

## 目录

- 商业模式与护城河
- 海外收入与全球竞争力
- 财报和现金流质量
- 资本配置
- 治理
- 否决条件与监控指标

## 商业模式与护城河

用一句话说明谁付钱、为何付钱、公司如何留下现金。再回答：

- 收入是否重复、分散且可预测？
- 公司是价格制定者还是价格接受者？
- 客户为何不选择竞争对手？
- 优势来自品牌、成本、技术、网络、渠道、转换成本还是监管许可？
- 护城河能否在 5 年后仍成立？证伪信号是什么？

把护城河证据映射到份额、毛利率、留存、价格、单位经济和资本回报，不能只写故事。

## 海外收入与全球竞争力

分别评价规模和质量：

- 海外收入占比高不等于质量高；检查利润、回款、本地化和客户集中度。
- 汇率带来的报表增长与真实销量/份额增长分开。
- 出口型低毛利代工与全球品牌、本地制造和全球服务网络分开。
- 使用全球份额、技术标准、成本曲线、品牌溢价和跨区域盈利证明竞争力。
- 披露关税、贸易壁垒、制裁、数据监管和供应链迁移风险。

## 财报和现金流质量

### 利润表

检查收入、毛利率、营业利润率、扣非/调整项、税率和少数股东损益。识别一次性收益、补贴、资产处置和会计口径变化。

### 现金流量表

比较净利润、经营现金流和 FCF 的多年关系。检查营运资本释放是否暂时抬高 FCF，资本开支是否被低估，以及并购现金流是否被排除在“自由现金流”之外。

### 资产负债表

检查现金质量、有息债务、租赁负债、存货、应收、商誉、养老金、担保和或有负债。对强周期公司使用低谷利润进行偿债压力测试。

## 资本配置

按每股内在价值评价历史决策：

1. 现有业务维持性投入是否充足？
2. 成长资本开支是否获得高于资本成本的回报？
3. 并购价格、整合效果、商誉和负债是否合理？
4. 分红是否由可持续 FCF 支撑？
5. 回购是否真正减少稀释后股本，并发生在合理价格？
6. 资产负债表是否保留穿越周期的能力？

不要因为分红多就自动给资本配置高分；如果放弃了高回报再投资或依靠举债分红，应降分。

## 治理

检查：

- 控股股东和管理层与中小股东利益是否一致。
- 关联交易、资金占用、担保和同业竞争。
- 高管激励是否绑定每股 FCF、ROIC 和长期回报，而不是规模。
- 审计意见、财务重述、监管处罚和管理层频繁变动。
- 信息披露是否稳定、可核实，并能解释错误决策。

重大治理红旗优先于估值便宜。

## 否决条件与监控指标

每家公司必须输出 3–6 个可验证的否决条件，例如：

- 每股 FCF 连续两年下降且无法由暂时投资解释。
- FCF 分红率持续超过 100%，净负债同步上升。
- 核心市场份额、价格能力或客户留存持续恶化。
- 增量 ROIC 低于资本成本，仍大规模扩张或并购。
- 海外单一市场风险上升，且公司缺乏本地化替代方案。
- 稀释后股本持续增长，抵消大部分 EPS 增长。
- 实际结果连续偏离中性情景的关键假设。

同时列出 3–6 个季度或年度监控指标，明确数据源和复核频率。
